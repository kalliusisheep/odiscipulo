# How to open the PR (prepared body is in docs/pr_description.md)

I cannot open the Pull Request automatically from this environment. I've prepared the branch and commits on feature/minhas-notas and added docs/pr_description.md with the PR body and checklist.

To open the PR manually:
1. Go to: https://github.com/kalliusisheep/odiscipulo/compare
2. Select feature/minhas-notas as the head branch and your default branch (e.g., main) as the base.
3. Copy the contents of docs/pr_description.md into the PR description, adjust if needed, and submit.

Once the PR is open, I can:
- Add reviewers and assignees (if you want).
- Update the PR with additional commits and respond to review comments.
